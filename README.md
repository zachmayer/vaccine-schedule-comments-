# Keep the vaccine schedule

A ten-minute, phone-first walkthrough for posting a public comment on HHS docket
HHS-OS-2026-0332, the Request for Information on the categories used in federal
vaccine recommendations. Comments close September 20, 2026, 11:59 PM Eastern.

Live page: https://zachmayer.github.io/vaccine-schedule-comments-/

The page hands you a prompt for Claude (or any AI chat). The AI asks three short
questions about you, writes the comment in your words, and you paste it into the
official form at regulations.gov.

Sources: the [Federal Register notice](https://www.federalregister.gov/documents/2026/08/24/2026-17250/request-for-information-categories-used-in-federal-vaccine-recommendations-and-the-role-of-shared)
and [Your Local Epidemiologist](https://yourlocalepidemiologist.substack.com/p/two-days-left-to-comment-on-hhss).

`index.html` is a single self-contained file with no dependencies.
